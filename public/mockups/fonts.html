One font for FloraScape Each card is set entirely in one font: headline, body, buttons, numbers and the tiniest labels.

Today the app loads five font families: Shrikhand, Mali, Gaegu, Caveat and Inter. Moving to one means a single download, one personality, and no mismatched weights. The font has to work for a chunky headline and for 12px labels like "Pick" or "~70 days", so check the bottom rows of each card.
