# Regression Audit — all V2 phases

Source documents: `docs/V2-PHASE1.md`, `V2-PHASE2.md`, and `V2-PHASE4.md` through `V2-PHASE10.md` (there is no Phase 3 spec). Scope: every numbered step of every phase, re-checked against the current code on `v2`.

**Precedence:** where a later phase's spec explicitly changes something an earlier spec describes, the later spec governs. In particular, Phase 10 requires every source file under `lib/`, `app/`, and `e2e/` to be TypeScript, so an earlier spec naming `x.js` is satisfied by `x.ts`.
