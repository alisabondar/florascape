Ten ways to draw the garden

All ten use the same sample garden (the home-page example: four beds, eight plants). Each one asks a different question for the gardener. 1–3 and 9 are about getting plants in the ground. 4–5 are about planning the season. 6, 7, 8 and 10 are about reading the plan at a glance. Any of them can be mixed with another.

1Square-foot grid

Each bed is split into 1 ft squares, and each square says what goes in it and how many. No measuring needed: the gardener lays string every foot and fills squares.

Tap a square.

For the gardener"4 beans here" is the most direct planting instruction there is. Square-foot gardening is a method many beginners already know.
Trade-offA tomato takes one square but needs the empty squares around it, which can look like wasted space. Patches don't line up with whole feet today, so the planner would need to snap zones to the grid.

2Planting day map

Patches are numbered in the order you plant them. The checklist on the side is the plan, and ticking a step colors that patch in as planted.

    For the gardenerTurns the sketch into a to-do list you carry outside. It ties straight into the existing Planted / Growing / Harvested stamps and XP.
    Trade-offThe numbers make the map busier. It works best as a mode you switch on ("Planting day") rather than the default view.

    3Tape-measure layout

    One bed as a blueprint: where each patch starts and ends, measured from the bed's left corner, with every planting hole marked. Built for laying out string lines.

    For the gardenerAnswers "where exactly do I dig?" Spacing stops being a number to remember, because every hole is drawn.
    Trade-offDense and technical, so one bed per view. It fits a "print layout" button better than the main result page.

    4Season scrubber

    Drag through the months and the garden changes with them: empty, sown, growing, ready to harvest, done. The plan becomes a season, not a single picture.

    For the gardenerShows when things happen and spots gaps: "the lettuce patch is free in July, plant fall carrots?" It leads naturally into succession planting.
    Trade-offNeeds dates for every plant, which the planting guide already has. A slider is less obvious on a phone, so add month chips there.

    5Sun & height

    The plan from above, with a side view underneath that shows how tall each plant gets and where its shadow falls. Sun comes from the side the user chose (south here).

    For the gardenerMakes "tall plants on the north side" visible instead of a rule to trust. Warns when a 5 ft tomato will shade the lettuce.
    Trade-offTwo drawings per bed take room. It could live as a toggle ("Show heights") under the main sketch.

    6Pixel diorama

    The same pixel art, drawn from a three-quarter view so the beds read as raised boxes and the side-on sprites finally match the camera. Every plant stands on its real spot.

    For the gardenerThe most charming option and the closest to today's style. It fixes the mixed top-down/side-on look that makes the current sketch hard to read.
    Trade-offBack rows hide behind front rows. It's harder to click a patch and to see exact spacing, so pair it with a flat view for editing.

    7Callouts

    A clean flat plan with nothing written on the beds. Labels sit outside each bed and point in with leader lines, so tags never cover plants.

    For the gardenerEvery patch gets its full name, count and spacing, even narrow ones that today show only "×7". It reads like a printed garden-center plan.
    Trade-offNeeds margin around each bed for labels. Beds packed close together need smarter label placement.

    8One bed at a time

    Pick a bed and it fills the screen, with plants at true spacing. A minimap shows where you are, and the list beside it is that bed's plants only.

    For the gardenerSolves "too small when scaled" outright: any garden size gets a big, legible bed. Best on phones and in the garden.
    Trade-offYou lose the whole-garden overview, which the minimap only partly covers.

    9Sowing diagram

    Each patch is drawn the way you plant it: seeds as dots along furrows, transplants as holes. Depth and spacing are printed on each row.

    For the gardenerSays what to physically do: "furrow ½″ deep, a seed every 6″". It separates direct-sown crops from bought starts, which matches the shopping list.
    Trade-offInstructional rather than pretty. It's strongest inside each plant's planting guide, zoomed to that one patch.

    10Watercolor poster

    A soft illustrated plan: each plant is a painted canopy as wide as it grows, with hand-lettered names. The one you'd print and pin in the shed.

    For the gardenerThe canopy size shows spacing without numbers: crowded blobs mean crowded plants. Feels like a keepsake, which fits the album and collecting theme.
    Trade-offLess precise for planting. It works best as the cover or print view, with a flat view for the details.
